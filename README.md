# Machine Learning and Deep Learning Course

## ¿Qué aprenderás?
- **Fundamentos de Machine Learning**: Descripción de machine learning, deep learning, redes neuronales, y algoritmos de ML como clasificación, regresión, clustering y reducción de dimensionalidad.
  
- **Modelos de Machine Learning**: Implementación de modelos de aprendizaje supervisado y no supervisado utilizando bibliotecas como **SciPy** y **Scikit-Learn**.
  
- **Despliegue en Apache Spark**: Implementación y despliegue de algoritmos de machine learning y pipelines en **Apache Spark**.
  
- **Modelos de Deep Learning**: Construcción de modelos de deep learning y redes neuronales utilizando **Keras**, **PyTorch**, y **TensorFlow**.

## Habilidades que obtendrás
- **Keras**: Biblioteca para redes neuronales profundas.
- **Transformers**: Modelos avanzados basados en arquitecturas de transformers.
- **LLMs (Large Language Models)**: Uso y comprensión de grandes modelos de lenguaje.
- **PyTorch**: Biblioteca de machine learning y deep learning.
- **Deep Learning**: Técnicas avanzadas para el entrenamiento y optimización de modelos profundos.
- **Artificial Intelligence (AI)**: Conceptos y aplicaciones prácticas de la inteligencia artificial.
- **Neural Networks**: Construcción y entrenamiento de redes neuronales artificiales.
