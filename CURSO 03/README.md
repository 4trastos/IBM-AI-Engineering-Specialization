# Aprendizaje Profundo con Keras y TensorFlow  
**by IBM**

## Acerca de este Curso

El aprendizaje profundo está revolucionando muchos campos, como la visión por computadora, el procesamiento de lenguaje natural y la robótica. Keras, una API de redes neuronales de alto nivel escrita en Python, se ha convertido en una parte esencial de TensorFlow, haciendo que el aprendizaje profundo sea accesible y sencillo. El dominio de estas técnicas abrirá muchas oportunidades en la investigación y la industria.

Este curso cubre el uso de Keras y su integración con TensorFlow 2.x para mejorar la funcionalidad de los modelos. Aprenderás a:

- Crear capas y modelos personalizados en Keras.
- Desarrollar redes neuronales convolucionales (CNNs) avanzadas.
- Construir modelos transformadores para datos secuenciales y series temporales.
- Aplicar principios de aprendizaje no supervisado para la optimización de modelos y bucles de entrenamiento personalizados.
- Desarrollar y entrenar redes neuronales profundas de refuerzo (Deep Q-Networks - DQNs).

El curso también incluye laboratorios prácticos en cada lección para reforzar los conceptos aprendidos y un proyecto final en el que desarrollarás un modelo de clasificación utilizando el aprendizaje por transferencia.

## Contenido del Curso

1. **Introducción al Aprendizaje Profundo**  
   Conceptos básicos de redes neuronales, capas y modelos con Keras.

2. **Redes Neuronales Convolucionales (CNNs)**  
   Construcción y entrenamiento de CNNs avanzadas para visión por computadora.

3. **Modelos Transformadores**  
   Trabajo con datos secuenciales y series temporales utilizando Keras y TensorFlow.

4. **Aprendizaje no Supervisado**  
   Técnicas de optimización y bucles de entrenamiento personalizados.

5. **Aprendizaje de Refuerzo con DQNs**  
   Desarrollar agentes de refuerzo que aprendan de su entorno.

6. **Proyecto Final**  
   Construcción de un modelo de clasificación utilizando aprendizaje por transferencia.

## Requisitos Previos

Este curso está dirigido a ingenieros de IA en formación y estudiantes que desean aprender TensorFlow y Keras. Se requiere:

- Conocimiento práctico de Python.
- Conocimientos básicos de matemáticas, incluyendo gradientes y matrices.
- Fundamentos de aprendizaje profundo utilizando Keras.

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/tuusuario/deep-learning-keras-tensorflow.git
    ```

2. Navega al directorio del proyecto:
    ```bash
    cd deep-learning-keras-tensorflow
    ```

3. Instala las dependencias requeridas:
    ```bash
    pip install -r requirements.txt
    ```
